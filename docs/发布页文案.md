## 技能简介（推广词，正文 198 字，≤200 合规）

领导要覆盖图，还在Excel里点坐标、手动描点？【台账坐标转QGIS图层】一条经纬度台账一键变成可编辑QGIS工程：多图层GeoPackage+双击即开项目，自带配色、WGS84坐标与内置卫星底图；独创测地线覆盖圈，半径圆、圈内自然村计数、高亮规则、分类汇总导出。58个共享基站、246个自然村实测，覆盖162个与逐站核对零差异。纯内网零依赖，QGIS自带一套开箱即跑，一条命令替代半天手工建图。

## 功能特性

### 1. 台账转 QGIS 图层（六步流程）
- 含经纬度的 Excel/CSV 台账 → 多图层 GeoPackage（WGS84/EPSG:4326），**可编辑、可补点**
- 双击即开的 `.qgs` 项目：分类配色、默认视图范围、项目 CRS、内置 Esri 卫星底图
- 内网友好：全程零外部依赖（QGIS 自带 ogr2ogr + 无头 Python）

### 2. 空间覆盖圈分析
- 测地线半径圆（如 1.5km）：Haversine 大圆距离圈内对象精确计数
- 生成圆多边形图层 + 圈内对象清单字段
- QGIS 规则高亮（如覆盖数 ≥5 单独高亮）、字段标注、按字段分类汇总导出 Excel

### 3. 实战坑全记录（省去踩坑时间）
打开白板根因、缓冲圆无效几何（PROJ Invalid latitude）、UTF-8 BOM 破坏列匹配、控制台乱码误判、Esri 瓦片 URL 顺序、GCJ-02 偏移、内网底图主机连通实测——20 余项全部固化在技能内。

## 适用场景
- 运营商网优/客响/规划：基站工参、铁塔站址、投效评估、乡村覆盖规划
- 监控与点位台账：防溺水、治安视频、接入网机房、户外前端点位
- 园区/物业/设计院：凡"Excel 里有经纬度，想在 GIS 里看图、画圈、数数量"

## 环境要求
- Windows + QGIS 3.36+（`bin\ogr2ogr.exe`、`bin\python-qgis.bat`）
- 系统 Python（pandas/openpyxl）
- 全程本地、零第三方依赖，内网可用

## 使用示例
覆盖圆一键脚本（QGIS 自带 Python）：
```
python-qgis.bat scripts/coverage_circle.py --gpkg X.gpkg --center 中心层 --target 对象层 \
    --radius_km 1.5 --out 圆层名 --center_field 基站名称 [--target_field 村名]
```

## 典型输出
- `<名称>.gpkg`（多图层，可编辑补点）+ `<名称>.qgs`（项目）
- `使用说明.md`、`QGIS底图叠加清单.md`
- 覆盖圆图层、覆盖自然村清单 Excel、分类统计 Excel（如 ABCD）
